2. The "look-for" vector u (one learned vector, not per-position)
u

Think of u as "what should a token look like to get a high weight". It has the same size as a token (D=3).

OLD way vs NEW way

OLD — fixed weight per position
tokens_w

A stored number for each position. Token at position 0 always gets 0.5 — even if the content changes to "the" or "quantum". The weight is blind to meaning.

NEW — weight computed from content
w[0] = u · cat = ?

The weight is u · token. "cat" gets one weight, "the" gets another — because their vectors differ. The weight now reflects meaning.
